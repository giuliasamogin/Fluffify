Política de Privacidade

Última atualização: 29 de setembro de 2026.

1. Informações coletadas

Os formulários podem guardar nome e e-mail localmente para simular uma conta.

2. Dados de cadastro e simulação

O carrinho, favoritos, tema, histórico de pedidos e cadastro são armazenados no LocalStorage do navegador.

3. Uso das informações

Os dados servem exclusivamente para demonstrar funcionalidades de uma aplicação web.

4. Cookies e LocalStorage

O projeto utiliza LocalStorage e SessionStorage; não há banco de dados real.

5. Segurança

Não use dados reais ou senhas reais neste projeto acadêmico.

6. Compartilhamento

O projeto não envia os dados para um servidor.

7. Direitos

Você pode limpar os dados do site pelas configurações do navegador.
